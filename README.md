# FunLang

**FunLang** — это функциональный, статически типизированный язык программирования, написанный на Go. Проект вдохновлен книгой Thorsten Ball *"Writing An Interpreter In Go"*, но расширяет её оригинальную концепцию, добавляя систему типов, поддержку интерфейсов (work in progress), оптимизацию хвостовой рекурсии LSP и форматтер.

## Ключевые особенности

- **Статическая типизация:** Проверка типов перед интерпретацией AST. Поддержка базовых типов, массивов, хэш-таблиц и сигнатур функций.
- **Продвинутая система типов:** Поддержка объединения (`|`) и пересечения (`&`) типов. (work in progress)
- **Структурное программирование:** Ключевые слова `interface` и `impl` для описания структур и реализаций. (wip)
- **Оптимизация хвостового вызова:** Необходима для функционального подхода (отсутствие циклов) — рекурсия не переполняет стек, если вызов функции происходит в `return`.
- **Отсутствие процедур на уровне синтаксиса:** let и return - единственные инструкции в языке, как следствие любая функция должна возвращать значение, это же касается любых других выражений.
- **Встроенный инструментарий:** 
  - **LSP-сервер:** Поддержка автодополнения, диагностики ошибок и других функций.
  - **Formatter:** Встроенный форматтер кода (fun fmt).

## Установка

Скачайте последнюю сборку для своей системы из раздела [Releases](https://github.com/PrsMik/funlang/releases).

---

Или же убедитесь, что у вас установлен [Go](https://golang.org/). Клонируйте репозиторий и соберите проект:

```bash
git clone https://github.com/yourusername/funlang.git
cd funlang
go build -o fun main.go
```

## Использование

Встроенные команды:

```bash
# Запуск REPL
./fun

# Интерпретация файла с кодом
./fun run <file.fun>

# Форматирование файла
./fun fmt <file.fun>

# Запуск LSP-сервера (по умолчанию TCP на 127.0.0.1:5007)
./fun lsp

# Запуск LSP-сервера через stdio
./fun lsp -mode=stdio
```

## Обзор синтаксиса

```funlang
return puts("Hello world!");
```

### Переменные и базовые типы

funlang имеет следующие встроенные типы

```funlang
let x: int = 10; // целое число, размер зависит от платформы
let isTrue: bool = true; // логическое значение
let greeting: string = "Hello, World!"; // UTF-8 строка
```

В funlang переменные объявляются с использованием `let`, при этом указание типа обязательно (точка с запятой в конце инструкций также обязательна):

```funlang
let x: int = 10;
let isTrue: bool = true;
let greeting: string = "Hello, World!";
let add: fn(int, int) -> int = fn(a, b) {
    return a + b;
};
```

### Структуры данных
Язык поддерживает массивы и хэш-таблицы:

```funlang
// Массивы
let arr: [int] = [1, 2, 3, 4, 5];

// Хэш-таблицы
let dict: {string: int} = {
    "apple": 1,
    "banana": 2
};
```

### Управляющие конструкции
Поддерживаются полность `if/else`, а также частично `switch` (wip). Согласно правилам языка об инструкциях, они являются выражениями и возвращают значения из своих веток.

```funlang
// puts возвращает количество выведенных символов
let x: int = if (x > 5) {
    return puts("x is greater than 5");
} else {
    return puts("x is 5 or less");
};

// switch не поддерживается в v0.2.2
let x: int = switch x {
    case 1 { return puts("One"); }
    case 2 { return puts("Two"); }
    default { return puts("Other"); }
};
```

### Функции и хвостовая рекурсия
Функции являются объектами первого класса. Указание типов параметров и возвращаемого значения обязательно. Оптимизация хвостового вызова поддерживается автоматически:

```funlang
let add: fn(int, int) -> int = fn(a: int, b: int) -> int {
	return a + b;
};

// демонстрация хвостовой рекурсии
let factorial: fn(int, int) -> int = fn(n: int, acc: int) -> int {
	return if (n == 0) {
		return acc;
	} else {
		return factorial(n - 1, acc * n);
	};
};

return puts(factorial(6, 1));
```

### Интерфейсы и реализации (WORK IN PROGRESS)
Вместо классических классов funlang предлагает структурную типизацию через интерфейсы и блоки `impl`:

```funlang
// Объявление типа-интерфейса (не поддерживается в v0.2.2)
let Animal: type = interface {
    let speak: type = fn() -> string;
};

// Реализация интерфейса (не поддерживается в v0.2.2)
let Dog: Animal = impl (Animal) {
    let speak: fn() -> string = fn() -> string {
        return "Woof!";
    };
};
```

### Встроенные функции
- `len(obj)` — возвращает длину строки или массива.
- `push(arr, element)` — добавляет элемент в конец массива (возвращает новый массив).
- `tail(arr)` — возвращает новый массив без первого элемента.
- `puts(val)` — вывод значений в консоль.
